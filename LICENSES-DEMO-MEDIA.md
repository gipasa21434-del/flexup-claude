# Demo media licensing

All 10 videos in `FlexUp/Resources/DemoMedia/` (and their `_thumb.jpg` covers) were generated by
`scripts/generate_demo_media.sh` using only FFmpeg's built-in synthetic sources
(`gradients`, `mandelbrot`, `life`, `cellauto`, `geq`, `aevalsrc`). No third-party footage,
photos or music were used. Captions are drawn with the DejaVu Sans font (free license).
"Music titles" shown in the demo feed are fictional labels for the synthesized tones.

The generated media is part of this project and may be redistributed with it.

`LocalTestMedia/` (git-ignored) is for the developer's own test clips only and is never committed.
