# FLEX UP

**Лови момент. Задавай тренд.**

FLEX UP — нативное iOS-приложение коротких вертикальных видео на Swift + SwiftUI: лента 9:16 со свайпами и
предзагрузкой, лайки, комментарии, подписки, поиск, публикация с обрезкой, и четыре собственные фишки —
**FLEX CHALLENGE**, **DUO REACT**, **MOOD FEED**, **FLEX STREAK**. Бэкенд — Supabase (Auth + Postgres + Storage
с Row Level Security). Без ключей приложение полностью работает в **демо-режиме** на устройстве.

> Статус проверки — честно: бизнес-логика (Swift-пакет `FlexCore`) и схема БД с RLS прогнаны тестами на Linux.
> iOS-часть (SwiftUI/AVFoundation) **ещё ни разу не компилировалась в Xcode** — среда разработки была Linux-сервером.
> Первая реальная сборка произойдёт в GitHub Actions на macOS. См. раздел [«Что проверено»](#что-проверено-и-что-нет).

## Возможности

| Раздел | Что есть |
|---|---|
| Онбординг и аккаунт | Приветствие (4 слайда), вход/регистрация по email+паролю с валидацией, сброс пароля (Supabase), гостевой режим, 3 тестовых демо-аккаунта, редактирование профиля и аватара, закрытый аккаунт, выход, удаление аккаунта |
| Лента | Полноэкранные 9:16, вертикальный свайп (UICollectionView с пейджингом), автопауза неактивных, цикл, предзагрузка соседних, пул ≤3 плееров, «Для тебя» / «Подписки», лайк (двойной тап с анимацией), комментарии, сохранение, подписка, системный Share Sheet, меню жалобы/«не интересно»/блокировки, кнопка звука, pull-to-refresh, экран «всё посмотрено» |
| Звук | Старт без звука по умолчанию (`.ambient`, уважает переключатель «Бесшумно»); звук включается только явно; пауза при отключении наушников и звонке |
| Поиск и тренды | Люди / ролики / хештеги, подсказки и история (локально), тренды, челлендж дня, фильтр по настроению, сортировка, экран хештега |
| Создание | Системный PhotosPicker, запись камерой (с экраном-объяснением прав), демо-клип для симулятора, обрезка фрагмента до 60 с по таймлайну с кадрами, выбор обложки, подпись с автодополнением хештегов, настроение, видимость, прогресс обработки и загрузки, отмена, повтор при ошибке |
| Социальное | Профили, статистика, сетка роликов, сохранённое, лайкнутые, подписки, комментарии с удалением своих (и любых под своим роликом), уведомления в приложении с фильтрами |
| Настройки | Приватность, кто может комментировать, заблокированные, фильтр хештегов, автоплей/звук/повтор/экономия трафика, кэш (размер + очистка), уведомления, стрик, симуляция сети в демо, сброс демо, «как работают рекомендации», лицензии |
| **FLEX CHALLENGE** | Ежедневная тема с таймером, участие одной кнопкой (тег подставляется), рейтинг участников (лайки + 2×комм. + 3×репосты + сохранения), прошлые и будущие темы |
| **DUO REACT** | Реакция на чужой ролик: запись/выбор видео → **реальная склейка на устройстве** (AVMutableComposition: сверху оригинал, снизу реакция, смешанный звук) или ответ-ссылка; страница «реакции на ролик»; уведомление автору |
| **MOOD FEED** | 5 настроений; лента фильтруется по отмеченному автором настроению или словарю тегов. Это правила, не ИИ |
| **FLEX STREAK** | Необязательные дневные цели (5 просмотров / 3 взаимодействия / 1 публикация — хватит одной), стрик с одним «прощённым» днём в неделю, календарь 14 дней, 7 достижений. Без пушей и тёмных паттернов, выключается |

Интерфейс на русском, архитектура готова к локализации (`en.lproj` с переводом основных строк и описаний разрешений).
Тёмная/светлая тема, Dynamic Type, Safe Area, VoiceOver-метки, области касания ≥44 pt, Reduce Motion отключает сложные анимации.

## Архитектура

```
FLEX-UP/
├── FlexUp/                      iOS-приложение (SwiftUI, MVVM)
│   ├── App/                     точка входа, AppModel (состояние), табы, роутинг, Keychain
│   ├── DesignSystem/            цвета/градиенты, кнопки, скелетоны, тосты, пустые состояния
│   ├── Media/                   PlayerPool (AVQueuePlayer+Looper), MediaStore, обрезка/обложка/DUO-склейка
│   ├── Features/                Feed, Search, Create, Profile, Comments, Challenges/Mood/Streak, Settings
│   └── Resources/               Assets (иконка, launch), DemoMedia (10 синтетических роликов), локализация
├── Packages/FlexCore/           чистая бизнес-логика (Foundation only, тестируется на Linux):
│                                модели, валидация, хештеги, рекомендации, стрик, челленджи, поиск,
│                                DemoBackend (локальный) и SupabaseBackend (REST, без SDK)
├── FlexUpTests/, FlexUpUITests/ unit- и UI-smoke-тесты приложения
├── supabase/migrations/         схема БД, RLS, триггеры, RPC, Storage-политики
├── supabase/tests/              тесты RLS/поведения на чистом PostgreSQL
├── scripts/                     генерация демо-видео/иконок, тест БД
├── project.yml                  спецификация XcodeGen (FlexUp.xcodeproj генерируется из неё)
└── .github/workflows/ios-build.yml
```

- **Deployment target: iOS 16.0** (iPhone, портретная ориентация). Swift 5 language mode, Xcode 16+.
- Внешних зависимостей **нет** (Supabase через `URLSession`).
- Протокол `FlexBackend` — один интерфейс для `DemoBackend` и `SupabaseBackend`. Режим выбирается автоматически:
  есть `SUPABASE_HOST` + `SUPABASE_ANON_KEY` → Supabase, иначе → демо (в UI помечено «ДЕМО»).
- Видео: загрузка в Supabase Storage с побайтовым прогрессом и отменой, проигрывание прогрессивного MP4;
  поле `hls_url` поддерживается клиентом (приоритетнее MP4), но **сервис транскодинга в HLS не входит в проект**
  (нужен внешний сервис, например Mux/Cloudflare Stream/AWS MediaConvert — платно).

## Быстрый старт (демо-режим)

Нужен Mac с Xcode 16+.

```bash
brew install xcodegen
```

```bash
git clone https://github.com/<you>/FLEX-UP.git && cd FLEX-UP && xcodegen generate && open FlexUp.xcodeproj
```

Выбери схему **FlexUp** и симулятор iPhone → Run. Онбординг → «Пропустить» → нажми тестовый аккаунт
`demo@flexup.app` (пароль у всех: `flexup2026`) или «Смотреть как гость».

Свои ролики для ручной проверки: положи `.mp4` в папку `LocalTestMedia/` в корне и снова выполни `xcodegen generate` —
они появятся в демо-ленте. Папка в `.gitignore` (чужие ролики не должны попадать в публичный репозиторий).

Для запуска на своём iPhone из Xcode: Signing & Capabilities → выбери свою команду (подойдёт бесплатный Apple ID,
приложение будет работать 7 дней), поменяй `FLEXUP_BUNDLE_ID` в `Config/Base.xcconfig` на уникальный.

## Подключение Supabase

1. Создай проект на supabase.com (бесплатного тарифа хватает для теста; лимиты Storage/трафика смотри на сайте).
2. Примени миграцию: `supabase link --project-ref <ref>` и `supabase db push`, либо вставь
   `supabase/migrations/20261113000000_init.sql` в SQL Editor.
3. Authentication → Providers → Email: включи; при желании — подтверждение email (приложение это обрабатывает).
   Для писем сброса пароля добавь Redirect URL.
4. Скопируй `Config/Secrets.example.xcconfig` → `Config/Secrets.xcconfig`:
   ```
   SUPABASE_HOST = abcdefgh.supabase.co
   SUPABASE_ANON_KEY = eyJ...
   ```
5. Челленджи: миграция создаёт темы на 30 дней. Продлевать — `select public.seed_daily_challenges(30);`
   (или по расписанию через pg_cron).

Anon-ключ публичный по дизайну Supabase — доступ к данным ограничивают RLS-политики. `service_role` ключ в
приложение **никогда** не кладётся.

## GitHub Actions: сборка, архив, IPA

Workflow `.github/workflows/ios-build.yml` запускается на push в `main`/`develop`/`release/**`, на pull request и
вручную (Actions → iOS Build → Run workflow). Джобы:

| Джоб | Runner | Что делает |
|---|---|---|
| FlexCore unit tests | ubuntu + Swift 6.0 | `swift test` бизнес-логики |
| Supabase schema + RLS tests | ubuntu + Postgres 16 | применяет миграцию, гоняет 47 проверок RLS/триггеров |
| Build, test & archive | macos-15 | XcodeGen → unit-тесты на симуляторе → UI-тесты → `xcodebuild archive` для `generic/platform=iOS` без подписи → артефакты `.xcarchive.zip`, `.xcresult`, логи |
| Signed IPA | macos-15 | **только если заданы секреты подписи**: временный keychain → профиль → подписанный archive → `xcodebuild -exportArchive` с `ExportOptions.plist` → `.ipa` (опционально TestFlight) → удаление keychain |

Без секретов результат: **«архив собран, IPA требует Apple code signing»**. Неподписанный `.xcarchive` нельзя
установить на iPhone — и мы не выдаём его за IPA.

### Пошагово от пустого репозитория
1. github.com → New repository → `FLEX-UP` (лучше Public: для публичных репозиториев стандартные раннеры бесплатны;
   в приватных macOS-минуты расходуются с множителем ×10 от бесплатной квоты — проверь актуальные условия в
   Settings → Billing).
2. Залей код:
   ```bash
   git remote add origin https://github.com/<you>/FLEX-UP.git
   ```
   ```bash
   git push -u origin main
   ```
3. Открой вкладку **Actions** → «iOS Build» → дождись зелёных джобов (≈15–25 мин).
4. Внизу страницы запуска — раздел **Artifacts**: `FlexUp-unsigned-xcarchive`, `build-logs-and-test-results`,
   и при настроенной подписи — `FlexUp-signed-ipa-<method>`.

### Подпись и IPA (Settings → Secrets and variables → Actions)
| Секрет | Откуда взять |
|---|---|
| `IOS_TEAM_ID` | developer.apple.com → Membership |
| `IOS_P12_BASE64` | Keychain Access → сертификат *Apple Distribution* (ad-hoc/app-store) или *Apple Development* → Export .p12 → `base64 -i cert.p12 \| pbcopy` |
| `IOS_P12_PASSWORD` | пароль, заданный при экспорте |
| `IOS_PROVISION_PROFILE_BASE64` | developer.apple.com → Profiles → профиль для твоего Bundle ID → `base64 -i profile.mobileprovision \| pbcopy` |
| `IOS_BUNDLE_ID` | необязательно (берётся из профиля) |
| `IOS_EXPORT_METHOD` | `ad-hoc` (по умолчанию), `development` или `app-store` |
| `SUPABASE_HOST`, `SUPABASE_ANON_KEY` | необязательно — без них IPA будет в демо-режиме |
| `ASC_KEY_ID`, `ASC_ISSUER_ID`, `ASC_KEY_P8_BASE64` | необязательно — автозагрузка в TestFlight при `app-store` |

Секреты не печатаются в логах, сертификат живёт только во временном keychain и удаляется в шаге `always()`.

## Установка на iPhone

Легальные способы (все требуют Apple-подписи):
- **Xcode + свой iPhone** — бесплатный Apple ID, сборка живёт 7 дней.
- **Ad Hoc IPA** — платный Apple Developer Program (на момент написания $99/год — проверь на developer.apple.com),
  UDID iPhone должен быть зарегистрирован в аккаунте и включён в профиль. Установка: Apple Configurator, Finder
  (перетащить IPA на устройство) или любой MDM.
- **TestFlight** — тот же платный аккаунт, приложение в App Store Connect, метод `app-store`; до 10 000 тестеров по ссылке
  (внешние — после короткой проверки Apple).

## Рекомендательный алгоритм

Прозрачные правила (это **не** обученная ML-модель), одинаковые в `FlexCore/Recommendation.swift` и в SQL `feed_for_you`:

```
score = 2·подписан_на_автора
      + 0.6·интерес(хештеги, автор)      ← растёт от лайков/сохранений/комментов/репостов/досмотров,
                                            падает от «не интересно» и быстрых пролистываний, затухает
      + 3·совпадение_с_настроением
      + 1.5·0.5^(возраст_ч / 48)          ← свежесть
      + ln(1+взаимодействия)/10 + min(взаимодействия/просмотры, 1)
      − 4·уже_просмотрено
затем разнообразие: один автор не чаще раза в 3 ролика (клиент) / штраф 1.5 за каждый следующий ролик автора (сервер)
```
Ограничения: нет коллаборативной фильтрации и анализа содержимого видео; клиентский профиль интересов хранится на
устройстве и в серверную формулу не передаётся (сервер учитывает подписки, настроение, просмотры и вовлечённость).

## Безопасность и модерация

- RLS на всех таблицах: видимость роликов (`everyone`/`followers`/`only_me`, закрытые аккаунты, блокировки, скрытые
  модератором) проверяется на сервере функцией `can_view_video`; лайки/сохранения/жалобы приватны.
- Счётчики пишут только триггеры; пользователь может обновлять лишь разрешённые колонки (column grants).
- Rate limiting в триггерах: публикации 10/ч, комментарии 10/мин, подписки 60/мин, лайки 120/мин, жалобы 20/ч
  (ошибка `rate_limited`, клиент показывает понятное сообщение; дублируется на клиенте для мгновенного отклика).
- Storage: загрузка только в папку `<user_id>/`, лимиты размера и MIME-типов.
- UGC: жалобы на ролики/комментарии/аккаунты, блокировка (скрывает контент в обе стороны и рвёт подписки),
  удаление своих роликов/комментариев, модерация комментариев под своим роликом, **удаление аккаунта** в приложении.
- Сессия — в Keychain (`AfterFirstUnlockThisDeviceOnly`). Ключей и паролей в репозитории нет.
- Не собираем геолокацию, контакты, рекламные идентификаторы; история поиска и интересы — только на устройстве.
- Разрешения камеры/микрофона/фото запрашиваются только при действии, с предварительным экраном-объяснением.

## Известные ограничения
- Нет транскодинга в HLS/адаптивного битрейта (нужен внешний платный сервис); ролики — MP4 (`faststart`).
- Push-уведомления не настроены (нужен APNs-ключ); уведомления — только внутри приложения.
- Бакеты Storage публичные: файл роликов `only_me` недоступен через API/ленту, но доступен по прямой ссылке,
  если её знать (UUID в пути). Для строгой приватности — приватный бакет + signed URLs.
- Удаление аккаунта удаляет строки `storage.objects`; для гарантированного удаления файлов в S3 на хостинге
  Supabase лучше вызывать Storage API из Edge Function.
- Лайки на комментариях — только визуальные (локальные).
- Монтажа (фильтры, текст, музыка) нет — только обрезка, обложка и DUO-склейка.
