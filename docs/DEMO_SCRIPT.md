# Сценарии для съёмки видео

## 60-секундная демонстрация

| Время | Что делать | Что увидит зритель |
|---|---|---|
| 0–5 с | Запуск приложения | Графитовый экран, неоновый логотип FLEX UP, слоган «Лови момент. Задавай тренд.» |
| 5–10 с | Онбординг → «Пропустить» → тап `demo@flexup.app` | Мгновенный вход в демо-аккаунт, лента стартует |
| 10–18 с | Свайпы вверх/вниз, двойной тап | Полноэкранные ролики без задержки, взрыв сердечек, счётчик +1 |
| 18–24 с | Комментарии → написать «🔥» → отправить | Шторка с комментарием сверху, счётчик на ролике растёт |
| 24–32 с | Иконка смайлика → «Спокойно» | **MOOD FEED**: лента перестраивается, чип «Настроение: Спокойно» |
| 32–40 с | Поиск → баннер челленджа → «Участвовать» → «Демо-клип» → Далее → Опубликовать | **FLEX CHALLENGE**: таймер, рейтинг, публикация с прогрессом |
| 40–50 с | На ролике кнопка Duo → «Записать реакцию» → демо-клип → Опубликовать | **DUO REACT**: прогресс «Склеиваем…», готовый ролик сверху-снизу |
| 50–56 с | Огонёк в ленте | **FLEX STREAK**: цели дня, календарь, достижения «Первый флекс» / «В челлендже» |
| 56–60 с | GitHub → Actions → артефакты | Зелёные джобы и `.xcarchive` / `.ipa` |

## Обработка ошибок (на камеру)
Профиль → ⚙️ → «Сеть (симуляция)» → «Нет сети» → вернуться в ленту, потянуть вниз → понятная ошибка «Нет сети» с
кнопкой «Повторить». Вернуть «Нормальная сеть» → «Повторить» → лента загружается.
«Медленная сеть» → видно скелетоны загрузки и прогресс публикации, который можно отменить.

## Полный сценарий проверки
1. Гость: «Смотреть как гость» → лайк → появляется «Нужен аккаунт».
2. Регистрация: новый email, слабый пароль → подсказка; нормальный → вход.
3. Профиль → Редактировать → имя, ник, аватар из фото → Готово.
4. Поиск: «даша» → профиль → Подписаться → вкладка «Подписки» в ленте.
5. Меню «…» на ролике → Пожаловаться → причина → Отправить (ролик исчезает); Заблокировать автора.
6. Настройки → Заблокированные → Разблокировать.
7. Создание из медиатеки (на устройстве), обрезка до 10 с, выбор обложки, видимость «Только я».
8. Удаление своего ролика из меню «…».
9. Настройки → Удалить аккаунт.
