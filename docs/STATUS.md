## Известные риски / вероятные баги до первой сборки
1. Возможны ошибки компиляции SwiftUI-кода (не собирался в Xcode). CI их покажет — исправляются точечно.
2. Пейджер на `UICollectionView` + `UIHostingConfiguration`: стоит проверить поведение на iPhone SE (маленький экран) и
   при быстром свайпе.
3. Склейка DUO REACT: трансформации для видео с поворотом (снятых фронтальной камерой) нужно проверить на устройстве.
4. UI-тесты на общих раннерах GitHub бывают нестабильны — в workflow они не блокируют сборку архива.
5. Лайки на комментариях только визуальные.
